# SongScope v0.3 实施记录

本文记录 `docs/implementation-v0.3.md` 各 checkpoint 的可复核结果。本分支已经满足实施契约第12节；最终状态仍以这里记录的命令输出、提交和 CI 为准。

## Checkpoint 0：基线、来源与存储决策

- 分支：从包含 corpus-first 规范提交 `2a3ff9e` 的本地 `main` 创建 `codex/corpus-first-v03`；
- 当前事实层：PostgreSQL + PostGIS，已有 source work/item/locator、assertion/evidence、event、appointment 和 service episode；
- 当前正式输入：`data/curated/`，共享 Zod schema 校验后确定性重建数据库；
- 当前 API：人物、仕宦、事件、断言证据、来源和实体搜索，尚无 corpus/unit/passage/全文检索/coverage 语义；
- 当前静态模式：从同一 curated JSON 生成 verified 投影，架构可扩展；
- 当前偏航：一级导航、首页和全局搜索仍以苏轼时间轴、地图、人物网络和 prototype 数据为中心；
- prototype 依赖：`src/data/songData.ts` 仍被首页统计、人物网络和数据模型页直接导入；
- 来源审计：固定目录 revision `2535238` 发现496卷，全部卷页可取得，原始 wikitext 约15.95 MiB；
- 存储与许可决定：见 [`adr/001-corpus-snapshot-storage.md`](adr/001-corpus-snapshot-storage.md)。

## Checkpoint 3：查询与 API

- 新增共享响应 schema，覆盖 corpus context、目录、卷、passage detail、文本 occurrence、实体 passage 反查、纪事、coverage、导出 metadata 和静态检索分片；
- PostgreSQL repository 新增目录、来源单元、卷段、相邻 passage、全文 occurrence、实体三层反查、神宗本纪纪事和版本覆盖查询；
- 稳定端点已实现：`/api/corpus`、`/api/corpus/:sourceItemSid/units`、`/api/units/:sid/passages`、`/api/passages/:sid`、`/api/search/text`、`/api/entities/:sid/passages`、`/api/research/annals`、`/api/datasets/:version/coverage`；
- 文本查询只统计原始 source text 中精确、非重叠 occurrence，并返回 Unicode code point 偏移、passage SID、卷次、顺序、revision 与覆盖；
- 实体反查分别返回字符串 occurrence、已消歧 annotation 和 accepted assertion 的 passage/evidence 回链；苏轼的繁体原文查询与卷338正式断言映射保持分层；
- 新增离线静态投影构建：496个逐卷文件、31个16卷检索分片、目录、coverage、annals 和苏轼回归实体投影；全部以 API 同一 schema 校验；
- 静态生成目录约88 MiB、532个文件，加入 `.gitignore`；生产 build 从固定本地输入生成，不访问网络；
- 初始生产 bundle 不包含 corpus 正文：JavaScript 358.14 kB（gzip 103.04 kB），语料按卷/查询懒加载；
- API 单元测试和真实数据库 projection 测试覆盖 occurrence 语义、496卷目录、passage 相邻导航、实体层次、纪事与 coverage。

## Checkpoint 4：研究界面

- 一级导航替换为史料、检索、纪事、实体、研究查询、数据版本；品牌按钮单独返回 corpus-first 首页；
- 首页显示《宋史》原文检索、五种目录篇类、固定 snapshot/dataset version、496卷覆盖摘要、神宗本纪切片和代表性查询，不再显示 prototype 数字；
- 史料页支持篇类/卷浏览、source/readable 切换、段落选择、上一段/下一段、稳定引用、revision、审核状态、候选标注、断言回链和许可/署名入口；
- 检索页支持篇类、卷次、review status、可重放 URL 参数、文本上下文、总命中数、CSV/JSON 导出和 passage 回跳；
- 纪事页按卷十四至十六原文顺序展示原始纪年和候选统计，并可筛选含除授动作词候选的段落；不生成公历月日；
- 实体页显式分开字符串出现、已消歧 annotation 和 accepted assertion evidence backlink；苏轼只作为 v0.2 回归实体；
- 数据版本页显示 expected/discovered/acquired/validated/segmented/searchable/reviewed、candidate annotation、新增 slice accepted assertion 为0、异常、来源 revision 和许可；
- 删除 `src/data/songData.ts` 及旧总览、地图、人物网络、时间轴、数据模型 prototype 运行模块；新增正式运行边界测试；
- 用无 API 的 production preview 和 headless Chrome 实查首页、卷14阅读、全书“徙知”查询及数据版本页；静态查询得到260个明确标记的文本 occurrence。
