## Phase 2 — 除授与官制

- 官、职、差遣、阶、勋、爵拆分
- 官职本体与历代沿革

## Phase 3 — 批量史料数据

- CBDB 人物、亲属、社会关系导入
- CHGIS 历史地名和行政区导入
- 《宋史》列传、表与本纪的实体识别工作流
- 史料断言、冲突和校勘界面

## Phase 4 — 专题研究

- 密州及北宋蝗灾、旱灾与赈济
- 元祐党人与新旧党政治网络
- 进士籍贯、同年关系与社会流动
- 诗词创作地点、意象与唱和网络
- 黄河水患、地方治理与官员响应

## Phase 5 — 平台化

- PostgreSQL/PostGIS 与 API
- 用户研究集、筛选器和可分享视图
- CSV/JSON/GeoJSON 导入导出
- 数据版本、引用和研究快照
- 中英文界面与公开数据发布
