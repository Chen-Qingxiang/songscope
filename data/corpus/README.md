# 《宋史》语料数据许可与署名

`songshi-wikisource/` 保存 SongScope v0.3 固定的中文维基文库《宋史》电子转录快照及其确定性派生分段。

## 权利边界

- 《宋史》抽象作品为公有领域作品；
- 中文维基文库页面的协作转录、标点和修订贡献按页面及站点标示的 Creative Commons Attribution-Share Alike 4.0 条款再利用；
- corpus 数据及由该转录直接派生的 passage 不适用仓库根目录的 MIT 代码许可；
- SongScope 的代码仍按根目录 `LICENSE` 所列 MIT License 发布。

来源：<https://zh.wikisource.org/wiki/宋史>

每个 source item 在 `manifest.json` 和对应卷文件中保存 canonical URL、revision ID、revision timestamp、history/attribution URL 和 checksum。引用或再发布时应保留这些元数据及本说明。
